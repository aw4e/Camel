## Camel 0.4.1: fits every display scale, safer cleanup, signed updates

### Fixes
- **Laptops with display scaling (125%, 150%).** The notch window is now sized in whole screen pixels, so the bottom edge is no
  longer cut off. Labels that would run past their tile (such as *Minimal notch* on Controls) and mixer channel names shrink to
  fit instead of being clipped.
- **Mixer.** A fader at zero no longer touches the mute button, and the strips sit further from the rounded bottom corners.
- **Minimal notch.** The thin line is a little longer and thicker, and its corners no longer flare out.
- **Weather.** When Windows gives no location, Camel asks again every minute, so switching on location access in Windows
  settings shows the weather right away. `city <name>` in Spotlight still works without location access.

### Safer
- **Updates are signed.** Every release carries `camel.exe.sig`, an Ed25519 signature checked against a key built into Camel.
  An update without a valid signature is never installed. This is the first release that carries one; from now on Camel only
  installs signed updates.
- **Leftover cleanup** never offers anything under Windows, WindowsApps or your own folders (Desktop, Documents, Downloads…),
  nor a folder another installed program still uses. Locked files are deleted at the next restart only after a second
  **Clean up** click; when something cannot go to the Recycle Bin, Windows asks before deleting it.
- **Uninstallers of per-user programs** start without administrator rights.
- **Start with Windows** runs elevated only when Camel sits under `Program Files`.
- **`kill` in Spotlight** matches the exact program name, so `kill se` no longer reaches system programs.
- **Settings.** Saving can no longer leave an empty file after a crash or power cut, and updating no longer switches the
  weather back on if you turned it off.

### Also
- If Camel crashes, the reason is written to `%APPDATA%\Camel\crash.log`.
- Building from source needs Rust 1.95 or newer.
