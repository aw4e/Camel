## Camel 0.4.2: a Stats page, real icons in Spotlight

### New
- **Stats page.** A live look at the PC: CPU, memory, disk, network and battery, with a usage-history graph and the busiest
  processes.
- **Spotlight shows real icons.** Application and file results now carry the program's own icon, taken from Windows, instead of
  a generic glyph. The icon falls back to the drawn placeholder when Windows has none for that file.

### Nicer
- **Usage-history graph** fills the area under each line, so CPU and memory are easier to read at a glance.
- **Spotlight's selected row** shows its action as a pill with a ↩ keycap, so it is clear what Enter will do.
